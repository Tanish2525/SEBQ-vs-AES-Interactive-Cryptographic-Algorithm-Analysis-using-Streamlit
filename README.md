# 🔐 SEBQ vs AES Encryption Analysis Tool

## 📌 Overview
This project is an interactive cryptography analysis tool developed as part of the **Principles of Cryptography** course. It provides a detailed comparative study of **SEBQ (Symmetric Encryption Based on Quasigroup)** and **AES (Advanced Encryption Standard)** through encryption, decryption, performance benchmarking, and avalanche effect analysis.

The application is built using **Streamlit** and offers real-time, step-by-step visualization of cryptographic operations along with graphical performance insights.

---

## 🎯 Objectives
- Compare SEBQ and AES encryption algorithms  
- Visualize encryption and decryption steps in detail  
- Measure and compare execution performance  
- Analyze the avalanche effect for both algorithms  
- Provide an academic and practical understanding of cryptography  

---

## 🛠 Features
- 🔒 Encryption & 🔓 Decryption analysis  
- ⚡ Performance comparison  
- 🌊 Avalanche effect study  
- 📊 Algorithm comparison dashboard  
- 🔬 Deep dive into SEBQ & AES internals  
- 📈 Interactive charts using Plotly  

---

## 🧠 Algorithms Covered
### 🔥 SEBQ
- Quasigroup-based symmetric encryption  
- Experimental and research-oriented  

### 🔷 AES
- AES-256 with CBC mode  
- Industry-standard encryption
